# VAgent · AI 视频制作

输入想法或上传参考图，VAgent 可以整理角色与场景、规划分镜、生成镜头并拼接成片。你可以在时间轴上逐镜调整，也可以开启「Agent 全自动」，一次提交后在对话中查看进度。

## 首次启动

1. 下载源码并解压到新目录，运行 `python -m pip install -r requirements.txt`，再运行 `python vagent_app.py`。打开终端显示的本地地址，默认是 `http://127.0.0.1:8000`。
2. 新安装的项目列表为空。点击右上角「API 设置」，分别为语言、图片和视频模型填写自己的 Base URL、API Key 和模型标识，保存设置。「测试」在本地检查配置是否完整。全自动制片需要支持图片输入的语言模型、兼容的图片服务和支持 H3 全能参考的视频服务。
3. 创建第一个项目，再进入对话。全自动审核和导出需要 FFmpeg 与 FFprobe，两者都应在 `PATH` 中，也可以把 `VAGENT_FFMPEG` 指向它们所在的目录。

项目、消息和 API 配置保存在本机的 `vagent.db`，素材和成片保存在 `uploads/`。GitHub 源码包不包含这两项。更新已有安装时，程序会继续读取原数据库。

Windows 也可以双击 `start.bat` 启动本地服务并打开浏览器。

## 主要功能

| 入口 | 可以做什么 |
| --- | --- |
| 项目与对话 | 管理项目和分集，上传参考图，多轮讨论分镜，查询 API 用量，导出 Markdown 对话记录。 |
| 资产库 | 命名角色，生成三视图或场景概念图。修改资产时先看方案与草稿，再决定是否覆盖已有设定。 |
| 视频时间轴 | 编辑镜头提示词和时长，拆分镜头，批量补齐首帧，使用首帧或参考资产生成视频。 |
| 成片确认 | 对照镜头提示词、画面复述和一致性判断，单独重做镜头，播放和下载自动导出的 MP4。 |

### 2026-11-24 · 全自动制片与成片确认

- 在资产库打开角色详情可以修改名称。Agent 创建角色和场景资产时，可通过 `generate_assets` 的 `role_name` 和 `scene_name` 给它们命名。已有资产可在详情中改名。
- 视频页的「一键生成所有首帧」位于「一键生成所有镜头」上方，只补缺失的首帧。单镜已有首帧时，相应入口显示「重新生成首帧」。首帧生视频沿用单镜确认流程。
- 窗口恢复可见或重新获得焦点后，时间轴重新读取后台状态。生成失败的镜头可点击「点击重试」重新提交。

| 模式 | 如何开始 | 在哪里看结果 |
| --- | --- | --- |
| 手动 | 生成镜头视频后，在「成片确认」右上角点击「开始确认」。 | Agent 在每镜旁复述画面中的主体、动作和场景。可对照复述直接修改镜头提示词，修改会同步到时间轴。尚未出片的镜头显示「待生成视频」。 |
| Agent 全自动 | 在对话底部开启「Agent 全自动」，一次提交想法、图片或文本附件。运行期间由 Agent 操作，对话中显示各镜头进度。 | 全部镜头通过两项校验后自动导出。可在对话进度区或「成片确认」页播放、暂停和下载 MP4。 |

**全自动制片流程**

1. Agent 提取需要跨镜头复用的角色、场景和道具。来自上传图片的主体先转存原图，再生成三视图。来自文字的主体先生成三视图，再存入资产库。
2. Agent 结合分镜节奏和 H3 技能编写逐镜提示词，通过全能参考模式提交视频。同一任务最多同时处理两个镜头，每镜独立保存生成进度和校验结果。
3. 每次提交的视频任务最多轮询 15 分钟。服务重启会沿用已保存的任务编号与截止时间。轮询超时后，服务商端的任务仍可能继续运行。
4. 每镜先抽帧检查角色一致性，通过后再复述画面并与原分镜目标对照。发生可重试的生成或校验失败时，Agent 根据原因改写提示词并重新生成。每镜最多尝试三次，重试可能产生服务费用。鉴权或内容审核错误会提前结束。
5. 全部通过后按原分镜顺序拼接。任一镜头最终失败会显示原因并停止本次导出。成片播放期间后台进度刷新会保留播放位置。

手动确认页并排显示镜头提示词、Agent 画面复述和一致性判断，可直接「单镜重做」。对话输入区右侧显示用户输入轮次，以及最近一次规划请求使用的输入 token 数。模型上限未知时，可在语言模型设置中填写上下文容量。

确认页读取实际生成的视频，每镜按时间顺序抽取 9 帧，覆盖开头至片尾附近。自动审核还会对照首次提交的参考图和文字目标。结论仅覆盖抽样画面，音轨和采样间隙内的动作不在核验范围内。视频页原有的三帧角色一致度校验仍可独立使用。

成片复述采用随包提供的 [MiniMax H3 视频反推技能](skills/minimax-h3-video-reverse-skill/SKILL.md)，读取其中的画面观察和叙事确认规则。[上游固定版本](https://github.com/gnipbao/minimax-h3-video-reverse-skill/tree/2fd1cc182606b81b69e0a9dca31c6cc7c2e973af)

后台按镜头保存自动任务与审核结果。拿到视频任务编号并落库后，关闭浏览器不会中断任务；VAgent 服务重启后会接续仍在排队的自动任务。已有数据库会自动补充审核字段。

### 2026-11-22 · 资产草稿、参考图与镜头调整

- 最终提示词强制扩写：三项确认里选「Agent 自动补全」后，必须由语言模型扩写；
  超时 60s、失败重试一次，失败会明确报错，不再静默退回原始短句。
- 新增修改对象判断工具 `judge_modify_target`：返回资产 / 镜头 / 整片 / 不确定，
  后端分派工具前复用同一判断。
- 显式切换修复：用户说“不要改角色，改镜头”时不再出资产方案，改为更新镜头提示词。
- Agent 自动模式：新增 `generate_assets` 工具，先出角色三视图和场景概念图，完成后再生成视频。
- 资产修改两段式：先出变更方案，确认后生成草稿，再选择「保存到资产（覆盖）」
  或「不保存（后台保留）」。
- 资产会话稳定出方案：连续调整、外观评价词、模型漏调工具都有兜底。
- 资产改版幅度增强：大改版 prompt 强调“必须明显改变”，明显不满意时不再使用旧图参考。

**资产**

- 资产更新预览卡：Agent 消息直接显示新三视图/概念图，并带「去资产库查看」按钮。
- 资产预览缓存戳：URL 带 `?v=<updatedAt>`，重新生成后不再显示浏览器旧缓存。
- 计划卡「生成资产图」先创建全部资产生成中条目，再逐张出图。
- 最终提示词卡片「生成相关资产」后台异步生成，资产库立即显示生成中。
- 图片模型切换至 `doubao-seedream-5-5-261028`，参考图生图可用。

**视频**

- 镜头清单短标题：Agent 给每镜 6–14 字标题，旧镜头回退提示词摘要。
- Agent 判断逐镜时长：4–10 秒整数；创建后仍可在镜头详情手动改。
- 镜头涉及资产模式：末帧替换为「涉及资产」，启用后走 MiniMax H3 全能参考，
  提交提示词 + 资产图片 + 资产设定描述；支持用户勾选或 Agent 自动选择。
- 视频生成中主按钮显示「生成中...」并禁用，防止重复提交。
- 视频页左下角素材区替换为「校验 / 角色一致度」；已接通抽帧校验：成片后抽 3 帧与资产三视图比对，四态面板，不通过列出问题和帧缩略图。

**项目与界面**

- 新建/编辑项目弹窗去掉类型，描述改为两行整宽的「项目概括」。
- 项目封面自动取资产库最新一张真图，188px 完整显示；概括显示在标题下方描述两行。
- 聊天输入框默认 3 行、随内容自动增高，修复多行复制内容看似消失。
- 方案/草稿按钮点击后显示 ✓、禁用，并插入「正在生成…」消息。
- 对话框支持调用资产库跳转、资产预览卡与保存/不保存操作。

- 三视图改一张四格设定稿：设定清单驱动、灰阶背景、完整入画与成对结构对称硬句、出图视觉体检。
- 视频前固定资产硬闸：资产没有已出图的三视图/概念图时，不能提交视频。
- 抽帧校验接通：成片后抽 3 帧与资产三视图比对，返回通过/不通过、问题列表和帧缩略图。

### 2026-11-21 · 从创作想法到分镜

- 普通模式支持角色、场景和风格三项确认。简短回复会沿用上一轮讨论的素材和意图，最终提示词生成失败时保留草稿。
- 最终提示词可按镜头拆分，生成每镜标题与时长。「生成相关资产」可准备角色三视图与场景概念图，资产库会显示后台生成进度，对话中可预览新图。
- 镜头详情支持以 0.5 秒为单位调整时长，时间轴和导出裁切随之更新。「一键生成所有镜头」会在提交前提示确认，按镜头计费。
- 对话新增资产和镜头修改确认按钮、资产更新预览卡与视频页入口。分镜规划可读取 Rui-Skills 提供的参考资料。[技能许可](skills/rui-skills-client/LICENSE)

### 2026-11-20 · 视频进度与素材转存

- 支持用镜头首帧生成 MiniMax 视频，并按时间轴顺序拼接成片。视频页改进了任务进度和错误提示。
- 对话中已生成的图片可点击「转存到资产」保存图片及描述。转存复用原图，同一张图多次转存会定位到已有资产。

### 2026-11-19 · 多轮对话与媒体生成

- 对话支持多轮规划、创作追问和参考图输入，可根据项目及镜头扩写资产描述，并由用户决定是否采纳。
- 支持角色三视图、场景概念图和逐镜视频生成。可在视频页查看生成任务，在资产库放大查看图片。
- API 设置中可查看语言、图片和视频调用情况。对话支持 Enter 发送、Shift+Enter 换行和 Markdown 导出。
